AI Hand Tracking Tutorial

Tutorial Information:

YouTube Creator: Arun
Video Title: Python project : AI hand tracking using python ( Media pipe )

Description:
For this tutorial I followed a youtube video by Arun that shows how to create a hand-tracking program using Python, OpenCV, and MediaPipe.
The tutorial explains how to access the webcam using OpenCV and use MediaPipe to detect hands. The program tracks the user's hands and displays points and lines connecting the finger joints and other hand landmarks. 
While following this tutorial I learned how to use OpenCV to capture live video from my webcam and how MediaPipe processes the video to detect hand landmarks. I also learned how to display the tracking results on the webcam feed.
This is very useful for my project so i will be implementing the advice from him in my own project.
